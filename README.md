# CC FLIP 3D — เกมเปิดแผ่นป้าย Creative Commons

เกมสื่อการสอนวิชาเทคโนโลยี 4 ชั้นมัธยมศึกษาปีที่ 6 เรื่องจริยธรรมในการใช้เทคโนโลยี

## การเล่น
- **เปิดภาพปริศนา:** กระดาน 6 × 6 จำนวน 36 แผ่นป้าย/รอบ, ภาพปริศนา 4 รอบ และแอนิเมชันพลิกป้าย 3D (CSS)
- **คำถามสุ่ม:** คำถาม 54 ข้อ สุ่มเลือก 36 ข้อไม่ซ้ำภายในเกม พร้อมเฉลย คำอธิบาย และคะแนน
- **สำหรับครู:** เฉลยภาพ ใบ้คำตอบ ตั้งเวลา รีเซ็ตเกม เต็มจอ และสลับโหมด
- ไม่ต้องใช้ฐานข้อมูล ไม่มีการบันทึกคะแนนบนเซิร์ฟเวอร์

## เล่นออนไลน์
หลังเปิดใช้งาน GitHub Pages เว็บไซต์จะอยู่ที่:
**https://donut204.github.io/Creative-Commons-flip-3d/**

## แก้ไขคำถามและรูปแบบเกม
เวอร์ชันที่เผยแพร่เป็นไฟล์ HTML เดียว: `index.html`
- คลังคำถาม: ค้นหา `const QUESTIONS = [` และแก้รายการ `q('คำถาม', ['ตัวเลือก 1','ตัวเลือก 2','ตัวเลือก 3','ตัวเลือก 4'], 0, 'เฉลย')`
- ตัวเลขเฉลย `0` หมายถึงตัวเลือกแรก; `1` = ตัวเลือกที่สอง เป็นต้น
- ลักษณะการเปิดป้ายและคำถามอยู่ภายใน JavaScript ของ `index.html`
- CSS สำหรับแอนิเมชันและรูปแบบหน้าจออยู่ใน `<style>` ของ `index.html`

เปิด `index.html` ในเบราว์เซอร์เพื่อทดลองแบบออฟไลน์ได้ทันที

## ติดตั้ง GitHub Pages
1. เข้า `Settings > Pages` ใน Repository
2. เลือก `Build and deployment > Source > GitHub Actions`
3. Workflow `.github/workflows/pages.yml` จะเผยแพร่เว็บไซต์เมื่อ push ไปที่ `main`
4. ดูสถานะในแท็บ `Actions`

## การทดสอบ
ต้นฉบับของเกมมีชุดทดสอบสุ่มคำถาม 7 รายการและผ่านในสภาพแวดล้อมพัฒนา (25 พ.ย. 2569)  
เว็บไซต์นี้เป็นสื่อประกอบการสอน ไม่ได้เป็นเว็บไซต์อย่างเป็นทางการของ Creative Commons  
ดูเงื่อนไขสัญญาอนุญาตได้ที่ https://creativecommons.org/licenses/
