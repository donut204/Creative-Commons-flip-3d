# CC FLIP 3D — เกมเปิดแผ่นป้าย Creative Commons

เกมสื่อการสอนวิชาเทคโนโลยี 4 ชั้นมัธยมศึกษาปีที่ 6 เรื่องจริยธรรมในการใช้เทคโนโลยี

## การเล่น
- **เปิดภาพปริศนา:** กระดาน 6 × 6 จำนวน 36 แผ่นป้าย/รอบ, ภาพปริศนา 5 รอบ (CC, BY, NC, ND, SA) และแอนิเมชันพลิกป้าย 3D (CSS)
- **สำหรับครู:** เฉลยภาพ ใบ้คำตอบ ตั้งเวลา Think Timer 10/15 วินาที รีเซ็ตเกม และเต็มจอ
- ไม่ต้องใช้ฐานข้อมูล ไม่มีการบันทึกคะแนนบนเซิร์ฟเวอร์

รูปสัญลักษณ์ใช้เวกเตอร์ SVG ที่ถอดเส้นจากภาพ PNG ทั้ง 5 ภาพที่ผู้ใช้ส่งให้ (เก็บสำรองใน `assets/` และฝังอยู่ใน `index.html`) เพื่อให้คมชัดบนจอโปรเจกเตอร์ โดยเกมสุ่มลำดับ 5 ภาพโดยไม่ซ้ำภายในชุด และซ่อนชื่อคำตอบจนกว่าจะเฉลย

## เล่นแบบออฟไลน์ (ไม่ต้องมีอินเทอร์เน็ต)

เกมเวอร์ชันล่าสุดเป็น **ไฟล์ HTML เดียว** รวม CSS, JavaScript และภาพสัญลักษณ์ Creative Commons ทั้ง 5 ภาพแล้ว ไม่ใช้ Google Fonts หรือบริการออนไลน์ในการเล่นเกม

**วิธีที่ 1 — ดาวน์โหลดทั้ง Repository**
1. กดปุ่ม **Code → Download ZIP** บนหน้า GitHub
2. แตกไฟล์ ZIP ก่อน (Extract All)
3. ดับเบิลคลิก `index.html` เพื่อเล่นด้วย Chrome, Edge หรือ Firefox
4. ปิด Wi-Fi แล้วเล่นได้ตามปกติ — ไม่ต้องติดตั้งโปรแกรมหรือเปิดเซิร์ฟเวอร์

**วิธีที่ 2 — ดาวน์โหลดเพียงไฟล์เดียว**
- ไปที่ `index.html` บน GitHub แล้วกด **Download raw file** (หรือเปิด Raw แล้ว Save As `index.html`)
- ดับเบิลคลิกไฟล์ `index.html` เพื่อเล่นได้ทันที โดยไม่ต้องคัดลอกโฟลเดอร์ `assets/`

> ข้อควรทราบ: ฟอนต์จะใช้ฟอนต์ภาษาไทยที่มีในเครื่องแทนฟอนต์ออนไลน์ และลิงก์ Creative Commons ในส่วนท้ายจะเปิดเว็บไซต์ภายนอกได้เฉพาะเมื่อเชื่อมต่ออินเทอร์เน็ตเท่านั้น ฟังก์ชันเกม, Think Timer, เปิดแผ่นป้าย, คำใบ้ และเฉลยภาพทำงานออฟไลน์

## แก้ไขภาพและการเล่น
เวอร์ชันที่เผยแพร่เป็นไฟล์ HTML เดียว: `index.html`
- รายการสัญลักษณ์อยู่ใน `const REVEAL_CARDS = [` ภายใน `index.html`; ไฟล์ต้นทาง SVG อยู่ใน `assets/` หากต้องการแก้ภาพ ต้องฝัง SVG ใหม่ใน HTML
- ลำดับภาพสุ่มไม่ซ้ำภายใน 5 รอบ
- เกมมีโหมดเดียวคือเปิดภาพปริศนา โดยใช้ Think Timer ระหว่างการอภิปรายได้
- CSS สำหรับแอนิเมชันและรูปแบบหน้าจออยู่ใน `<style>` ของ `index.html`

เปิด `index.html` ด้วย `file://` ได้โดยตรง แม้ดาวน์โหลดเฉพาะไฟล์ HTML เพราะมี SVG ทั้งหมดฝังอยู่ในไฟล์แล้ว

## ติดตั้ง GitHub Pages
1. เข้า `Settings > Pages` ใน Repository
2. เลือก `Build and deployment > Source > GitHub Actions`
3. Workflow `.github/workflows/pages.yml` จะเผยแพร่เว็บไซต์เมื่อ push ไปที่ `main`
4. ดูสถานะในแท็บ `Actions`

## การทดสอบ
ตรวจ JavaScript syntax และการอ้างอิง DOM หลังทำโหมดเปิดภาพอย่างเดียว รวมทั้งตรวจว่าไม่มีการร้องขอฟอนต์หรือภาพจากอินเทอร์เน็ต (28 พ.ย. 2569)
